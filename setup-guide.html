😊 还需要一步就能开始使用

DeepSeek Harness 需要一个轻量的运行环境（Node.js），你的电脑上还没检测到它。请在有网络的情况下按以下步骤安装：

1
点击下方 打开 Node.js 官网下载页，下载 Windows 64 位 的 LTS 版本（长期支持版）。
2
双击下载的 .msi 文件安装，一路点"下一步"即可，保持默认选项不动。
3
安装完成后，点击下方 我已安装，重新检查 按钮，即可自动启动。
* 安装 Node.js 是官方免费、安全的，大小为几十 MB。安装后只需联网几秒即可完成 DeepSeek Harness 的首次启动。
